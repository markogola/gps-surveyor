How background route recording works

GPS Surveyor records a route as GPS points at an interval the user chooses. To keep recording while the phone is in a pocket or another app is open, it runs a location foreground service, only after the user taps Start recording.

What the video shows

  1. The user opens GPS Surveyor and goes to the Record tab.
  2. They choose an interval (5 seconds in the demo) and tap Start recording.
  3. A location foreground service starts and saves a GPS point at that interval.
  4. A persistent notification shows the route is being recorded, with the point count and distance.
  5. The user leaves the app; recording continues in the background and the notification keeps updating.
  6. Tapping the notification returns to the app.
  7. The user taps Stop & save: the service stops and the saved route is shown.
Permission
FOREGROUND_SERVICE_LOCATION, with a location foreground service type.
When it runs
Only between the user tapping “Start recording” and “Stop & save” (or the Stop button in the notification). It never starts on its own.
Why it is needed
Route recording is the app's core feature. Without the foreground service, recording would stop as soon as the screen turns off or the user switches app, leaving gaps in the route.
Background location
The app does not request ACCESS_BACKGROUND_LOCATION. Location is used only while the app is open or while a recording the user started is shown in the notification.
About the demo
Recorded on an Android emulator with a simulated location in Nairobi; some parts are sped up as marked.
